# L2D 配置编辑器 1.4.0 更新说明

## 计划图自动转换

- 计划节点的颜色现在直接决定正式节点类型：绿色转换为 `TouchIdle`，紫色转换为 `TouchDrag`，节点名称只作为自然语言备注。
- `TouchIdle` 会自动生成触发框、过渡动画和目标待机动画；`TouchDrag` 会自动生成触发框和过渡动画，但不改变待机动画。
- 顶部 `Idle`、`Drag` 按钮支持批量设置计划节点类型，右键菜单也可修改单个节点；未着色旧节点仍兼容原有 `touchidle<编号>-touch_idle<编号>` 写法。

## 双向同步与编辑体验

- 正式节点与计划主题按 UUID 双向绑定：在任一视图修改标题都会同步到另一边，正式图新建的 `TouchIdle`、`TouchDrag` 也会以正确颜色出现在计划图。
- 如果计划图没有改变结构，切换视图会保留正式节点已经摆好的位置；只有发生结构变化的分支需要重新安排。
- 拖动计划节点时，现有连线会实时跟随；靠近可接收节点时会显示指向新父级的虚线预览，无效或成环的目标会被排除。

## 编号与布局

- 转换器按计划图的树结构自动分配唯一编号：从最上方分支开始，沿上方路径从左到右走到底，再返回处理下面的同级节点，最后进入下一条主分支。
- 正式节点按计划图层级自动排列，计划标题与正式节点标题保持一一对应。
- 正式图新增金色 `固定` 操作，可锁定一个或多个功能节点的当前序号；重新转换时其他节点会自动绕开固定序号。
- 固定节点在正式图显示淡绿色边框，在计划图显示金色边框；再次点击 `固定` 可解除锁定。
- 固定节点不参与“优化连线”；参数表中只要有一行被固定，整张表都会保持原位。

## 连线布局

- “优化连线”采用统一行距、主链横排、分支连续占行的布局；不同一级分支不会互相穿插。
- 每个分支按照最拥挤的一层占用连续行，组内保持紧凑，下一组紧接下一行，不额外制造大段空白。

## 兼容性

- 图表文件格式仍为 v5，旧工程可以继续打开；新增的序号锁定和结构变更状态会随 JSON 保存。
- 旧计划数据会尽量根据现有正式节点恢复标题、颜色与节点类型。
- 推荐升级前备份重要业务 JSON。旧版编辑器会拒绝保存 v5 图表，以避免新字段静默丢失。
