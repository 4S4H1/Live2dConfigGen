# L2D Config Editor 1.2.0 更新说明

## 主要变化

- 修复从编辑器安装目录发起自更新时，交接 PowerShell 继承工作目录并阻止
  NSIS 替换旧目录的问题；安装目录激活加入约 5 秒的短暂占用重试。
- `L2DUpdateHost` 改为独立托盘进程。关闭编辑器不会停止 Host；托盘可显示、
  启停服务、复制地址或明确退出，升级后会恢复升级前的运行状态。
- 画笔不再需要开关：`Ctrl+左键` 直接绘制，`Ctrl+右键` 删除整条笔迹，
  `Esc` 取消正在绘制的笔迹。
- 新增左根右展的“计划模式”。正式图和计划图共享节点与连线内容，
  计划标题、层级、排序、折叠、分支颜色和视角独立保存并可撤销。
- 文档格式升级为 v4。1.2.0 可加载 v1–v3 并确定性生成计划布局；文件保存为
  v4 后，旧版会明确拒绝打开，以免计划数据被静默丢失。
- 新增用户级 `EditorToolService` 与右侧“AI 对话”面板，支持
  OpenAI-compatible `/v1/chat/completions`、流式响应、取消、工具循环和
  写操作确认。API Key 只从所配置的环境变量读取，不写入设置或历史。
- “导出到 CSV”现在直接导出当前内存图表，文件名包含当前 JSON 名称，
  同秒重复导出不会覆盖已有文件，最终文件通过原子替换发布。

## 升级与兼容说明

- 一个安装器同时维护编辑器和
  `%LOCALAPPDATA%\Programs\L2DUpdateHost` 两个独立程序根，卸载入口仍只有一个。
- 旧版独立 Host 会迁移为伴随组件；发布缓存
  `%LOCALAPPDATA%\4S4H1\L2DUpdateHost` 会保留。
- 升级前请正常保存业务文件。若安装根内混入 JSON、CSV 或图片工作文件，
  安装器会拒绝替换并提示先迁移，避免误删用户数据。
- 本版本提供应用内工具注册表和对话面板，不开放 MCP、外部 HTTP/RPC、
  Shell、进程、更新器或局域网服务工具。
