# L2D 配置编辑器 1.4.1 更新说明

## 计划图与正式图

- 旧工程迁移后，正式节点只按业务类型映射为绿色、紫色或中性计划主题，不再把正式图的装饰颜色带入计划图。
- 在计划图与正式图之间反复切换时，正式节点的自定义背景色、边框色和文字色会完整保留。
- 增加旧工程迁移、重新物化及真实窗口切换回归，防止两套视图互相覆盖外观数据。

## 画布编辑体验

- 双击重命名紧凑节点标题时，编辑框使用与原文一致的视觉字号，不再突然放大。
- 确认、取消或提交未变化的标题后，编辑控件会立即清理，并恢复标题栏原始尺寸。
- 打组中的节点移出原边界时，组框会自动扩大并继续包含该节点；显式放大的组框仍不会自行缩小。

## 固定节点显示

- 正式图和计划图的固定节点描边会与节点等比例缩放，远景下不再显得异常粗重。
- 正式图固定描边按两套画布的坐标比例加粗，使相同可视节点尺寸下与计划图的描边粗细基本一致。

## 兼容性

- 图表文件格式仍为 v5，现有 1.4.0 工程可直接打开，无需手动转换。
- 推荐升级前备份重要业务 JSON。旧版编辑器仍会拒绝保存无法安全识别的新格式数据。
