# 1.4.4

本版包含工程审查中确认的数据完整性、编辑与更新问题修复。

- 撤销/重做完整恢复自动生成字段、手工覆盖标记及对象顺序；打开损坏文件时保留当前编辑历史。
- 保留 parts_data 数值精度，隔离文档和节点快照，修复批量模板创建与表格粘贴边界问题。
- 修复文件重命名的路径、名称冲突及会话缓存问题；SVN 取消不再影响后续查询。
- AI 请求取消或重新发送后，旧确认不能继续修改图表；磁盘写入和异常模型回复不再中断对话。
- 修复更新缓存写入失败、旧缓存占用、HTTP 续传、单实例文件转交和中文安装文件清单处理。

完整修复与回归记录见 [工程审查报告](QA_AUDIT_2026-09-19.md)。

发布文件为 `L2DConfigEditor-Setup-1.4.4-x64.exe` 完整安装包和
`L2DConfigEditor-1.4.4.l2dupdate` 签名更新包。两者包含相同的编辑器和独立更新 Host。
沿用既有 Ed25519 发布密钥，最低支持版本仍为 1.0.0；1.4.3 用户可正常升级。
更新包可导入局域网 Host，完整安装包可直接覆盖安装。安装器未做 Authenticode 签名。
