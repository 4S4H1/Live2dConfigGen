# 1.4.3

本版修复计划图显示和工具栏交互，将图形版本历史统一为 SVN 已提交版本之间的比较，并暂时关闭尚未完善的监听器入口。

- **监听器暂不开放**：隐藏新建、编辑及历史子图预览入口，工具服务和粘贴也不能绕过限制。已有 v6 子图数据继续保留。
- **计划图文字**：缩小到 45% 以下仍绘制标题和备注，字号随卡片等比缩放。
- **视图与工具栏**：正式图／计划图按钮在两种主题下都有明确选中态。`Idle`、`Drag`、`固定` 仅在计划图显示；自动／手动创建、数值联动、简洁显示、优化布局及打组仅在正式图显示。计划图固定操作可以生成并锁定序号，转换和固定可一次撤销。
- **SVN 版本历史**：默认比较最近两次修改当前文件的 SVN 提交，两侧可选择任意已加载提交。当前本地编辑内容不参与比较；少于两次提交时给出提示。首次打开就能滚轮缩放和拖动平移，无需先点选修改项。
- **JSON 历史清理**：不再生成或回放内嵌快照及增量。旧 JSON 已有的 `history` 字典原样保留供兼容使用，不追加，不参与图表差异。没有该字段的 JSON 保存后也不会增加历史。
- **备注导出**：CSV 的 `desc` 为空时导出画布／参数表的备注 `tips`，明确填写的 `desc` 仍优先。继续使用带 BOM 的 UTF-8，保留中文标点和范围原值。本机 LibreOffice 自动导入、UTF-8 导入及另存验证通过；此前报告的乱码尚未复现，未作为已修复问题宣称。

发布文件：`L2DConfigEditor-Setup-1.4.3-x64.exe` 完整安装包和 `L2DConfigEditor-1.4.3.l2dupdate` 签名更新包。更新包包含 Ed25519 签名清单和安装器，安装器本身未做 Authenticode 签名。构建和验收要求见 [BUILDING.md](../BUILDING.md)。
