# L2D 配置编辑器 1.4.2 更新说明

## 备注与输入

- 自动保存等待当前编辑结束，不再每隔几秒关闭备注、节点字段、参数表或分组名称编辑框；中文输入法的候选输入也不会被自动保存打断。
- 备注显示与编辑使用相同字号，深浅主题和画布缩放下都保持一致，修复全局样式覆盖编辑字号的问题。
- 保存、导出及关闭会提交尚未按回车或失焦的卡片内容，避免遗漏刚输入的文字。
- 表单刷新其他字段时保留未提交内容和光标；一次提交多个字段时先收集所有输入，再整体更新，避免后面的输入被前面的更新覆盖。
- 切换节点时将草稿提交给原节点；取消选择后清空旧的属性绑定。
- 数字输入到 `-`、`.` 或 `-.` 等中间状态时不会报错或把已有可空整数清除。

## 保存与 CSV

- 使用撤销栈的真实保存标记，修复“保存 → 撤销 → 输入不同内容”后修改状态被误判为已保存的问题；切换文档仍保留正确的撤销与保存状态。
- 当前图表、批量和工具服务的 CSV 导出统一使用带 BOM 的 UTF-8，中文、繁体、换行、引号和 emoji 可正确往返读取。
- 批量导出采用临时文件和原子替换，转换或写入失败时保留原 CSV，并避免导出修改内存图表。
- 无法解码的旧 CSV 表头模板不会阻断导出，会回退到 schema 标准表头。
- CSV 业务列和节点导出规则保持兼容：独立备注节点仍属于画布辅助内容，不新增业务 CSV 行。

## 更新发布

- 隔离构建环境的 DLL 搜索路径，避免混入其他工具的不兼容 ICU 动态库导致成品无法启动；签名前增加成品 EXE 启动、打开文件和单实例转交验收。
- Host 切换最新版本失败时保留旧发布，并清理本次暂存版本，允许重新导入同一个包。
- 先完成新版本发布，再清理过期缓存；旧缓存被占用时延后清理，不再阻断新包发布。

## 安装与兼容

- `L2DConfigEditor-Setup-1.4.2-x64.exe` 同时安装编辑器和独立更新 Host，可直接覆盖安装旧版，无需先卸载。
- `L2DConfigEditor-1.4.2.l2dupdate` 使用原发布密钥签名，导入“局域网更新主机”后，其他编辑器可通过“检查更新”升级。
- 最低在线更新版本仍为 1.0.0；1.0.0 客户端需要手动填写 Host 地址，更高版本支持局域网自动发现。
- 图表格式仍为 v5，原有 JSON、工作区设置及 Host 发布缓存沿用。
