# L2D 配置编辑器 1.3.1 更新说明

## 计划图可读性与布局

- 计划图改为内容驱动的自适应卡片。中文、英文和混合标题会自动扩展到最多两行；只有确实超长的末尾内容才省略，悬停始终可查看完整标题。
- `touchidle<编号>-touch_idle<编号>-备注` 显示为三段式卡片：框名为蓝色、动画名为橙色、备注独立换行；长框名和动画名优先保留末尾编号。
- 计划图恢复独立的左根右展树形布局。节点通过 UUID、上下级和同级顺序与正式图对应，不再逐像素复用或修改正式图坐标、分组和参考图。
- 卡片尺寸参与树形排版与连线锚点计算，父主题在子树中垂直居中；深层导入图仍使用迭代式布局。
- 缩放低于 45% 才进入无文字概览，避免半缩小时文字突然消失；选中、搜索或按 `F` 定位时会自动恢复到可读缩放。

## 图表编辑与计划正式化

- 正式图和计划图各有独立画笔层。`Ctrl+右键` 连续扫掠会即时按整条删除笔迹，并作为一次撤销操作提交。
- 计划主题支持正式框名与动画名、带备注的正式条目和纯备注三种格式。符合规则的条目正式化为同 UUID 的 `TouchIdle`，纯备注保留为可连线但不导出的虚节点。
- 虚节点与 TouchIdle 使用一致的紧凑卡片样式；可编辑预期框名和预期动画名，填写任一项会自动转为同 UUID 的 TouchIdle。
- 修复计划图转正式图后连接显示不完整的问题，备注和虚节点均能显示输入/输出引脚及既有连接。

## 工具与稳定性

- 参数字段与触摸框、过渡动画统一为“短文本居中；溢出时左侧省略并右对齐”的布局策略。
- 新增只读“SVN 图表 Diff”：直接比较 SVN 文件版本与当前内存图表，按节点、连线、分组、计划层级、两层画笔和参考图显示结构化差异，不保存本地 Diff 历史。
- AI 批量图编辑支持批量增改删节点和连线；保留原子确认、单步撤销和 500 项操作上限，同时移除模型响应、工具参数和工具结果的旧大小限制。
- 安装器不再因安装目录内未知 JSON、CSV 或图片工作文件阻断升级或卸载；仍保留安装根目录、所有权、锁、签名、SHA-256 与失败回滚保护。

## 兼容性

- 图表文件格式仍为 v5。v1–v4 文件会安全迁移；旧计划主题不会根据标题被启发式改写。
- 推荐升级前备份重要业务 JSON；旧版编辑器会拒绝保存 v5 图表，以避免新字段静默丢失。
