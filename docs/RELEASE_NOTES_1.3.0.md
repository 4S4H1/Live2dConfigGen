# L2D Config Editor 1.3.0 更新说明

## 主要变化

- 画笔整线擦除升级为连续手势：按住 `Ctrl+右键` 滑动会即时隐藏扫过的整条
  笔迹，释放后一次提交；快速扫过、不同缩放和宽笔迹均使用空间候选筛选，
  整次手势只产生一个撤销步骤。
- 计划图新增独立画笔层。正式图和计划图分别保存、显示和撤销笔迹，切换视图
  或正式化计划节点时不会复制、转换或清空另一层笔迹。
- 文档格式升级到 v5，新增计划主题正式化状态和内部 `PlanPlaceholder` 虚节点。
  v1–v4 文件安全迁移，旧计划主题不会按标题启发式改写业务节点。
- 计划标题符合 `touchidle<编号>-touch_idle<编号>` 时，会转为保持同 UUID 的
  `TouchIdle`；左右编号独立，大小写不敏感，显示保留原文并用不同颜色区分框名
  和动画名。其他标题转为可连线但不参与 CSV、业务校验和功能节点导出的虚节点。
- 修复计划图转正式图时连接丢失的问题。节点 UUID、坐标、锁定、分组、层级以及
  入边、出边、多父边和引用边均保留；备注和虚节点也可显示连接引脚。
- 参数显示区域与触摸框、过渡动画统一溢出布局：短文本居中，长文本从左省略并
  右对齐，优先保留末尾编号。
- 新增只读“SVN 图表 Diff…”。可直接从 SVN 历史比较任意两个文件提交版本，
  或与打开对话框时的当前内存图表比较；按节点、字段、位置、连线、分组、计划
  层级、两套画笔和参考图片摘要展示结构化差异，不保存本地 Diff 历史。
- AI 已支持批量创建、修改、删除节点以及批量创建和删除连线。移除模型响应正文、
  工具参数和工具结果的旧大小上限，仍保留超时、取消、工具循环、单轮调用数、
  单批 500 项图操作和原子提交保护。
- 安装器改用受管文件清单。安装目录中的未知 JSON、CSV、图片和其他用户文件不再
  阻断安装或卸载，并会原地保留；旧 Host 元数据异常只记录警告并跳过清理。

## 升级与兼容说明

- 1.3.0 写出 `format_version: 5`；旧版编辑器会拒绝打开 v5 文件，避免新字段被
  静默丢失。升级前仍建议保存并备份重要业务文件。
- v1–v4 内容在内存迁移后再参与 SVN 图表 Diff；高于当前支持版本或损坏的 JSON
  会明确标记为不可比较。
- SVN Diff 依赖外部 SVN CLI，自动发现失败时可手动选择 `svn.exe`。认证只使用
  SVN 自身凭据缓存，不收集密码，也不会自动信任证书。
- 安装器仍保留安装根目录与所有权校验、进程和文件锁检查、分阶段替换、失败
  回滚、Ed25519 签名与 SHA-256 校验。
